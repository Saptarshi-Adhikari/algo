## 7. Multi-Provider Fallback Architecture
* **Configured Hierarchy**: `Ollama (Primary)` → `Gemini (Fallback)` → `OpenRouter (Fallback)` → `MockLLMProvider (Final Fallback)`
* **Fallback Verification**:
  1. **Ollama Operational**: Ollama processes requests. Gemini & OpenRouter are skipped.
  2. **Simulated Ollama Failure**: Router attempts `GeminiLLMProvider` if `GEMINI_API_KEY` exists in `.env`. If unconfigured, skips cleanly to OpenRouter/Mock.
  3. **All Providers Offline**: Router gracefully falls back to `MockLLMProvider` ensuring system resilience without crashing.
* **Security Audit**: API keys are read solely from `.env` and are never logged, printed, or exposed in UI/logs.

## 11. Known System Limitations & Scope
1. **Dynamic LLM Operand Syntax**: LLMs occasionally format indicator operands using non-standard naming (e.g., `1.5 * volume(sma_20)` or `bb_upper_20_2`). The `StrategyEvaluator` includes robust regex parsing and alias mapping to handle variations safely.
2. **Local Model Response Speed**: Generation latency for Qwen 2.5 7B ranges between 6s to 18s per turn on CPU/RAM, which is optimal for asynchronous research loops but not intended for ultra-high-frequency real-time execution.
3. **Paper Trading Only**: Live market trading is strictly disabled by design.
