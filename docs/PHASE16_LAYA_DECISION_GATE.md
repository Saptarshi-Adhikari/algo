# Phase 16 — Laya Decision Gate Policy

## Structured Decision Assessment
Phase 16 emits a structured multi-dimensional assessment rather than a single collapsed score:
- `data_availability_status`
- `collection_status`
- `evidence_status`
- `fresh_calibration_status`
- `data_drift_status`
- `prediction_drift_status`
- `calibration_drift_status`
- `regime_drift_status`
- `model_health_status`
- `economic_shadow_status`
